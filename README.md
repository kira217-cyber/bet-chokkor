# BetChokkor

`https://betchokkor.com` এর ক্লোন — Bajiman প্রজেক্টের ফাইল ও কোড স্ট্রাকচার অনুসরণ করে।

## ফোল্ডার

| ফোল্ডার | কী | অবস্থা |
| --- | --- | --- |
| `client/` | মূল সাইট (প্লেয়ার ফেসিং) | ডিজাইন সম্পূর্ণ, স্ট্যাটিক ডেটা |
| `affiliate/` | অ্যাফিলিয়েট প্যানেল | বাকি |
| `admin/` | অ্যাডমিন প্যানেল | বাকি |
| `server/` | API সার্ভার | বাকি |
| `scripts/` | BetChokkor CDN থেকে অ্যাসেট ডাউনলোডার | — |

## ক্লায়েন্ট চালানো

```bash
cd client
npm install
npm run dev
```

## অ্যাসেট

`client/public/assets/` এর সব ইমেজ BetChokkor এর CDN (`img.b971606.com`) থেকে
নেওয়া। নতুন অ্যাসেট লাগলে `scripts/asset-urls.txt` এ URL যোগ করে:

```bash
node scripts/download-assets.mjs
```

## ডিজাইন টোকেন

`client/src/index.css` এ মূল সাইটের পুরো টোকেন সেট আছে — ডার্ক নিউট্রাল
(`#292926` কনটেন্ট, `#1c1c1a` বেস) + গোল্ড অ্যাকসেন্ট (`#f9b901`)।

সাইজিংয়ের জন্য `--u` বেস ইউনিট: মোবাইলে `1vw` (স্ক্রিনের সাথে স্কেল করে),
৪৮০px এর উপরে ফিক্সড `3.75px`। ৩৭৫px viewport এ দুটো সমান, তাই একই মান
দুই জায়গাতেই ঠিক থাকে — মূল সাইট যেভাবে করে।

## স্ট্যাটিক ডেটা

সার্ভার তৈরি না হওয়া পর্যন্ত সব কনটেন্ট `client/src/data/` থেকে আসে:

- `siteData.js` — লোগো, ব্যানার, নোটিশ, নেভিগেশন, ফুটার, লাইসেন্স
- `gameData.js` — ৮টি ক্যাটাগরি ও তাদের ভেন্ডর, প্রোভাইডার, ইভেন্ট, ফিচার্ড গেমস

`globalSlice` / `globalGameSlice` এর thunk দুটো এখন এই ফাইলগুলো রিটার্ন করে।
সার্ভার এলে শুধু thunk এর ভিতরের অংশ API কলে বদলাতে হবে — বাকি কোড অপরিবর্তিত।
