# BetChokkor — Affiliate

অ্যাফিলিয়েট পার্টনারদের সাইট। ক্লায়েন্ট সাইটের একই ডার্ক + গোল্ড
প্যালেট ও ডিজাইন টোকেন, কিন্তু মার্কেটিং পেজের জন্য আলাদা লেআউট।

## চালানো

```bash
npm install
npm run dev        # http://localhost:5174
```

## পেজ

| রুট | কী |
| --- | --- |
| `/` | ল্যান্ডিং — হিরো, স্ট্যাট, কমিশন স্ল্যাব + ক্যালকুলেটর, তিন ধাপ, কেন আমরা, প্রোভাইডার, FAQ, CTA |
| `/login` | অ্যাফিলিয়েট লগইন |
| `/register` | অ্যাফিলিয়েট রেজিস্ট্রেশন |

## ভাষা

সব লেখা `src/data/locale.js` এ বাংলা ও ইংরেজিতে। হেডারের পতাকা থেকে
টগল, পছন্দ localStorage এ সেভ থাকে।

## স্ট্যাটিক ডেটা

`src/data/affiliateData.js` — স্ট্যাট, কমিশন স্ল্যাব, ধাপ, ফিচার,
প্রোভাইডার ও FAQ। server তৈরি হলে `globalSlice` এর thunk এই ফাইলের
বদলে API কল করবে, শেপ একই থাকবে।

## অ্যাসেট

লোগো, পতাকা, লাইসেন্স ব্যাজ ও ভেন্ডর লোগো `client/` থেকে কপি করা —
একই ব্র্যান্ড, তাই আলাদা ডাউনলোডের দরকার নেই। হিরোর ব্যানার দুটো
BetChokkor এর আসল অ্যাফিলিয়েট ক্রিয়েটিভ।
