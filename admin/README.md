# BetChokkor — Admin Panel

React 19 + Vite 7 + Tailwind v4 + Redux Toolkit। ক্লায়েন্ট সাইটের ডার্ক +
গোল্ড রঙেই বানানো, চলে `localhost:5175` এ।

## চালানো

```bash
cd admin
npm install
cp .env.example .env      # VITE_API_URL এ সার্ভারের ঠিকানা
npm run dev               # http://localhost:5175
```

সার্ভার (`../server`) আগে চালু থাকতে হবে।

## পেজ

| পাথ | কী | কে দেখে |
| --- | --- | --- |
| `/login` | লগইন | সবাই |
| `/` | ড্যাশবোর্ড — সংখ্যার কার্ড, ৭ দিনের চার্ট, সাম্প্রতিক কার্যক্রম | সব অ্যাডমিন |
| `/admins` | অ্যাডমিন তৈরি, রোল ও পারমিশন বদল, মুছে ফেলা | শুধু mother |
| `/profile` | নিজের ইমেইল ও পাসওয়ার্ড বদল | সব অ্যাডমিন (viewer পড়তে পারে) |

## লগইন পেজ

- প্রতারণা সতর্কতা ও একটাই হোয়াটসঅ্যাপ নম্বর — ঘূর্ণায়মান রঙিন ফ্রেমে
- ডেমো (view only) অ্যাকাউন্টের ইমেইল ও পাসওয়ার্ড, কপি বোতামসহ। সার্ভারে
  ডেমো অ্যাকাউন্ট কনফিগার করা না থাকলে বাক্সটা দেখানোই হয় না
- অ্যানিমেশন সব CSS এ — বাড়তি ডিপেন্ডেন্সি নেই, `prefers-reduced-motion`
  দিলে বন্ধ হয়ে যায়

প্যানেলের সব লেখা ইংরেজিতে — কেবল প্রতারণা সতর্কতার বার্তাটাই বাংলায়।

## রোল

- **mother** — সব পেজ, সব কাজ
- **sub** — শুধু টিক দেওয়া পেজগুলো
- **viewer** — সব পেজ দেখে, উপরে "View only" ব্যাজ থাকে, কোনো লেখা-কাজ করতে পারে না

`PrivateRoute` শুধু UI আড়াল করে। আসল বাধা সার্ভারের মিডলওয়্যারে — টোকেন
এডিট করে রোল বদলালেও API 403 দেয়।

## ফোল্ডার

```
src/api/axios.js          টোকেন হেডার + ৪০১ এ অটো লগআউট
src/app/store.js          Redux স্টোর
src/features/auth/        authSlice ও সিলেক্টর
src/PrivateRoute/         রুট গার্ড (motherOnly / perm)
src/RootLayout/           সাইডবার + টপবার শেল
src/pages/                Login, Dashboard, Admins, Profile, NotFoundPage
src/data/navigation.js    নেভ আইটেম, পারমিশন তালিকা, রোলের নাম
src/router/router.jsx     রুট টেবিল
```

## রেসপনসিভ

ডেস্কটপে বাঁয়ে স্থায়ী ২৬০px সাইডবার, মোবাইলে হ্যামবার্গার ড্রয়ার।
320 / 390 / 768 / 1366 / 1920 / 2560px — সব জায়গায় হরিজন্টাল ওভারফ্লো শূন্য।

নিজেই সেশন মুছে `/login` এ পাঠায়।
