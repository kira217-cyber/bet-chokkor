# BetChokkor — API Server

Express 5 + Mongoose 8। অ্যাডমিন প্যানেলের (`admin/`) ব্যাকএন্ড।

## চালানো

```bash
cd server
npm install
cp .env.example .env     # তারপর মান বসান
npm start                # ডেভেলপমেন্টে: npm run dev
```

`.env` কখনোই গিটে যায় না — `.gitignore` এ ব্লক করা।

## এনভায়রনমেন্ট ভেরিয়েবল

| নাম | কাজ | বাধ্যতামূলক |
| --- | --- | --- |
| `PORT` | সার্ভার পোর্ট (ডিফল্ট `5000`) | না |
| `MONGO_URI` | MongoDB কানেকশন স্ট্রিং | হ্যাঁ |
| `JWT_SECRET` | টোকেন সাইনিং কী, কমপক্ষে ৩২ অক্ষর | হ্যাঁ |
| `JWT_EXPIRE` | টোকেনের মেয়াদ (ডিফল্ট `7d`) | না |
| `CORS_ORIGINS` | কমা দিয়ে আলাদা করা অনুমোদিত অরিজিন; খালি রাখলে সব অরিজিন | না |
| `DEMO_ADMIN_EMAIL` | লগইন পেজে দেখানো ডেমো অ্যাকাউন্টের ইমেইল | না |
| `DEMO_ADMIN_PASSWORD` | সেই অ্যাকাউন্টের পাসওয়ার্ড | না |
| `NODE_ENV` | `production` হলে এরর মেসেজে বিস্তারিত যায় না | না |
| `MASTER_API_URL` | white-label মাস্টারের ঠিকানা — গেম, প্রোভাইডার ও ক্যাটাগরির উৎস | হ্যাঁ |
| `OPAY_URL` | অটো ডিপোজিটের পেমেন্ট পাতা বানানোর এন্ডপয়েন্ট | অটো ডিপোজিট চালালে |
| `PUBLIC_SERVER_URL` | গেটওয়ে ও গেম প্ল্যাটফর্ম কোথায় ফেরত ডাকবে | অটো ডিপোজিট চালালে |
| `PUBLIC_CLIENT_URL` | পেমেন্টের পর ব্যবহারকারী কোথায় ফিরবে | অটো ডিপোজিট চালালে |

API key ও টোকেন কোনোটাই `.env` এ নেই — গেম API key, OTP এর key আর
OraclePay এর business token তিনটেই অ্যাডমিন প্যানেল থেকে বসে আর
ডেটাবেসে `select: false` হয়ে থাকে। তাই কোনোটা বদলালে ডিপ্লয় লাগে না,
আর কোড বা `.env` ফাঁস হলেও টোকেন বেরিয়ে যায় না।

`JWT_SECRET` না থাকলে বা ৩২ অক্ষরের কম হলে সার্ভার চালুই হয় না — দুর্বল
সিক্রেট নিয়ে ডিপ্লয় হয়ে যাওয়া ঠেকাতে।

## প্রথম অ্যাডমিন

ডেটাবেস খালি থাকলে একবারই চালান:

```bash
node scripts/createFirstAdmin.js
```

পাসওয়ার্ড স্ক্রিনে একবারই দেখাবে — ডেটাবেসে শুধু bcrypt হ্যাশ থাকে, পরে
আর উদ্ধার করা যায় না। হারালে আবার এই স্ক্রিপ্ট দিয়ে নতুন অ্যাডমিন বানাতে হবে
(অথবা mother অ্যাডমিন প্যানেল থেকে পাসওয়ার্ড রিসেট করবে)।

## ডেমো অ্যাকাউন্ট

লগইন পেজে একটা `view only` অ্যাকাউন্টের ইমেইল ও পাসওয়ার্ড দেখানো হয়, যাতে
যে কেউ প্যানেলটা ঘুরে দেখতে পারে। `GET /api/admin/demo-credentials` ইচ্ছে
করেই খোলা রুট — এই অ্যাকাউন্টের পাসওয়ার্ড সবাইকে দেখানোই উদ্দেশ্য।

যে তিনটে শর্ত একসাথে না মিললে API কিছুই দেয় না:

1. `.env` এ `DEMO_ADMIN_EMAIL` ও `DEMO_ADMIN_PASSWORD` দুটোই থাকতে হবে
2. সেই ইমেইলের অ্যাডমিন ডেটাবেসে থাকতে হবে এবং রোল হতে হবে `viewer`
3. অ্যাকাউন্টটি সক্রিয় থাকতে হবে

তাই অ্যাকাউন্টটি মুছে ফেললে বা রোল বদলে দিলে বাক্সটা নিজে থেকেই মিলিয়ে যায়,
এবং ভুল করেও mother বা sub অ্যাকাউন্টের পাসওয়ার্ড এখান দিয়ে বেরোতে পারে না।
পাসওয়ার্ড ডেটাবেসে শুধু bcrypt হ্যাশ হয়েই থাকে — `.env` এর কপিটা কেবল
লগইন পেজে দেখানোর জন্য।

এই একটা অ্যাকাউন্টে ৫ বার ভুল পাসওয়ার্ডে লক হয় না। পাসওয়ার্ড এমনিতেই
পেজে লেখা, তাই লক করে brute force ঠেকানোর কিছু নেই — উল্টো যে কেউ ইচ্ছে
করে ভুল পাসওয়ার্ড দিয়ে ডেমো বন্ধ করে দিতে পারত।

## রোল

| রোল | পারে |
| --- | --- |
| `mother` | সব — অ্যাডমিন তৈরি, সম্পাদনা, মুছে ফেলা |
| `sub` | শুধু যেসব পেজের `permissions` দেওয়া আছে |
| `viewer` | সব দেখে, কিছুই বদলাতে পারে না (নিজের প্রোফাইলও নয়) |

রোল যাচাই সার্ভারেই হয় (`middleware/protectAdmin.js`) — ফ্রন্টএন্ডের গার্ড
শুধু UI লুকায়, নিরাপত্তা দেয় না।

## টার্নওভার কীভাবে এগোয়

টার্নওভার সাইটের ভিতরে গোনা হয় না — খেলার প্রতিটা রাউন্ডের খবর
white-label মাস্টার `/api/callback` এ পাঠায়, সেখান থেকেই এগোয়।

```
বাজি → /api/callback → ব্যালেন্স ঠিক করা
                     → টার্নওভারের অগ্রগতি
                     → অ্যাফিলিয়েটের গেম কমিশন
                     → GameHistory তে রেকর্ড
```

**ডিপ্লয়ের সময় white-label প্যানেলে এই সাইটের callback URL বসাতে হবে**
(`https://<সার্ভার>/api/callback`) — নইলে মাস্টার খবর পাঠাবে না, তাই
টার্নওভারও নড়বে না।

প্রোভাইডারের শর্ত সাইটজুড়ে এক নয়, **প্রতিটা টার্নওভারের নিজের** — তৈরির
সময় যে কনফিগ থেকে এসেছে (রেজিস্টার বোনাস, ডিপোজিটের বোনাস, বা অটো
ডিপোজিটের বোনাস) সেখান থেকে তুলে রাখা হয়। তাই পরে অ্যাডমিন নিয়ম
বদলালেও চলতি শর্ত বদলায় না।

- তালিকা খালি → যে কোনো প্রোভাইডার ১:১ গোনে
- প্রতিটা শতাংশ সেই প্রোভাইডারের **বাঁধা ন্যূনতম অংশ** — ৫০%+৫০% দিলে
  একটাতেই খেলে কখনো শেষ হবে না
- যোগফল ১০০ এর কম হলে বাকিটা **খোলা অংশ**, সেখানে যে কেউ জমা দিতে পারে
- যোগফল ঠিক ১০০ হলে খোলা অংশ নেই, তাই তালিকার বাইরের প্রোভাইডারে
  খেললে ওই টার্নওভারে কিছুই গোনে না

একই `serial_number` দুবার এলে কিছুই ঘটে না (`GameHistory.serialNumber`
unique) — নেটওয়ার্কের গোলমালে মাস্টার একই রাউন্ড আবার পাঠালেও টাকা
দুবার কাটে না।

## নিরাপত্তা

- পাসওয়ার্ড bcrypt (১২ রাউন্ড), স্কিমায় `select: false` — ভুল করেও রেসপন্সে যায় না
- পরপর ৫ বার ভুল পাসওয়ার্ড → অ্যাকাউন্ট ১৫ মিনিট লক (HTTP 423)
- এক IP থেকে ১৫ মিনিটে সর্বোচ্চ ২০ লগইন চেষ্টা, পুরো `/api` তে মিনিটে ৩০০ রিকোয়েস্ট
- ভুল পাসওয়ার্ড আর নেই এমন ইমেইল — একই বার্তা, তাই কোন ইমেইল আছে বোঝা যায় না
- `helmet`, CORS অ্যালোলিস্ট (`CORS_ORIGINS`), বডি সাইজ ১mb
- শেষ mother অ্যাডমিন মুছে ফেলা যায় না, নিজের রোল বা স্ট্যাটাস নিজে বদলানো যায় না
- `NODE_ENV=production` হলে ইন্টারনাল এরর মেসেজ বাইরে যায় না
- ফোন নম্বর সবখানে এক রূপে (দেশের কোড ও শুরুর শূন্য ছাড়া) — নইলে একই
  নম্বরে একাধিক অ্যাকাউন্ট খোলা যেত
- OTP কোড ডেটাবেসে নয়, মেমরিতে — ৫ মিনিটে মেয়াদ শেষ, ৬০ সেকেন্ডের
  আগে আবার চাওয়া যায় না, ৫ বার ভুল হলে নতুন কোড নিতে হয়
- ডিপোজিট অনুমোদন atomic দখল (`pending → approved`) দিয়ে, তাই দুই
  ট্যাবে বা দুবার ক্লিকে টাকা দুবার যায় না
- বোনাস ও টার্নওভারের হিসাব জমা দেওয়ার মুহূর্তেই snapshot হয় — পরে
  নিয়ম বদলালেও পুরোনো রিকোয়েস্টের হিসাব বদলায় না
- আপলোড শুধু ছবি (নাম ও MIME দুটোই মিলতে হয়), সর্বোচ্চ ৫MB, ফাইলের
  নাম সার্ভারই বানায়

## ড্যাশবোর্ডের ডেটা

`Admin Accounts` সংখ্যাটা আসল ডেটাবেস থেকে আসে। বাকি সংখ্যা (ইউজার,
ডিপোজিট, উইথড্র, অ্যাফিলিয়েট) আপাতত স্ট্যাটিক — কালেকশনগুলো এখন আছে,
তাই `routes/dashboardRoutes.js` এ শুধু কোয়েরিগুলো বসালেই হবে।

- অ্যাফিলিয়েট সাইটের লগইন/রেজিস্টার ও রেফারেল লিংক
