# BetChokkor — API Server

Express 5 + Mongoose 8। অ্যাডমিন প্যানেলের (`admin/`) ব্যাকএন্ড।

## চালানো

```bash
cd server
npm install
cp .env.example .env     # তারপর মান বসান
npm start                # ডেভেলপমেন্টে: npm run dev
```

`.env` কখনোই গিটে যায় না — `.gitignore` এ ব্লক করা।

## এনভায়রনমেন্ট ভেরিয়েবল

| নাম | কাজ | বাধ্যতামূলক |
| --- | --- | --- |
| `PORT` | সার্ভার পোর্ট (ডিফল্ট `5000`) | না |
| `MONGO_URI` | MongoDB কানেকশন স্ট্রিং | হ্যাঁ |
| `JWT_SECRET` | টোকেন সাইনিং কী, কমপক্ষে ৩২ অক্ষর | হ্যাঁ |
| `JWT_EXPIRE` | টোকেনের মেয়াদ (ডিফল্ট `7d`) | না |
| `CORS_ORIGINS` | কমা দিয়ে আলাদা করা অনুমোদিত অরিজিন; খালি রাখলে সব অরিজিন | না |
| `NODE_ENV` | `production` হলে এরর মেসেজে বিস্তারিত যায় না | না |

`JWT_SECRET` না থাকলে বা ৩২ অক্ষরের কম হলে সার্ভার চালুই হয় না — দুর্বল
সিক্রেট নিয়ে ডিপ্লয় হয়ে যাওয়া ঠেকাতে।

## ফোল্ডার

```
config/db.js              MongoDB কানেকশন
models/Admin.js           অ্যাডমিন স্কিমা
middleware/protectAdmin.js  টোকেন যাচাই + রোল গার্ড
routes/adminRoutes.js     অথ ও অ্যাডমিন ব্যবস্থাপনা
routes/dashboardRoutes.js ড্যাশবোর্ডের পরিসংখ্যান
utils/                    টোকেন জেনারেটর, রেসপন্স হেল্পার
scripts/createFirstAdmin.js  প্রথম mother অ্যাডমিন তৈরি
index.js                  অ্যাপ বুটস্ট্র্যাপ
```

## প্রথম অ্যাডমিন

ডেটাবেস খালি থাকলে একবারই চালান:

```bash
node scripts/createFirstAdmin.js
```

পাসওয়ার্ড স্ক্রিনে একবারই দেখাবে — ডেটাবেসে শুধু bcrypt হ্যাশ থাকে, পরে
আর উদ্ধার করা যায় না। হারালে আবার এই স্ক্রিপ্ট দিয়ে নতুন অ্যাডমিন বানাতে হবে
(অথবা mother অ্যাডমিন প্যানেল থেকে পাসওয়ার্ড রিসেট করবে)।

## রোল

| রোল | পারে |
| --- | --- |
| `mother` | সব — অ্যাডমিন তৈরি, সম্পাদনা, মুছে ফেলা |
| `sub` | শুধু যেসব পেজের `permissions` দেওয়া আছে |
| `viewer` | সব দেখে, কিছুই বদলাতে পারে না (নিজের প্রোফাইলও নয়) |

রোল যাচাই সার্ভারেই হয় (`middleware/protectAdmin.js`) — ফ্রন্টএন্ডের গার্ড
শুধু UI লুকায়, নিরাপত্তা দেয় না।

## API

| মেথড | পাথ | কে |
| --- | --- | --- |
| POST | `/api/admin/create-first-time` | শুধু ডেটাবেস খালি থাকলে |
| POST | `/api/admin/login` | সবাই (রেট লিমিটেড) |
| GET | `/api/admin/profile` | লগইন করা অ্যাডমিন |
| PUT | `/api/admin/profile` | লগইন করা অ্যাডমিন (viewer নয়) |
| GET | `/api/admin/admins` | mother |
| POST | `/api/admin/admins` | mother |
| PUT | `/api/admin/admins/:id` | mother |
| DELETE | `/api/admin/admins/:id` | mother |
| GET | `/api/dashboard/stats` | লগইন করা অ্যাডমিন |
| GET | `/api/health` | সবাই |

## নিরাপত্তা

- পাসওয়ার্ড bcrypt (১২ রাউন্ড), স্কিমায় `select: false` — ভুল করেও রেসপন্সে যায় না
- পরপর ৫ বার ভুল পাসওয়ার্ড → অ্যাকাউন্ট ১৫ মিনিট লক (HTTP 423)
- এক IP থেকে ১৫ মিনিটে সর্বোচ্চ ২০ লগইন চেষ্টা, পুরো `/api` তে মিনিটে ৩০০ রিকোয়েস্ট
- ভুল পাসওয়ার্ড আর নেই এমন ইমেইল — একই বার্তা, তাই কোন ইমেইল আছে বোঝা যায় না
- `helmet`, CORS অ্যালোলিস্ট (`CORS_ORIGINS`), বডি সাইজ ১mb
- শেষ mother অ্যাডমিন মুছে ফেলা যায় না, নিজের রোল বা স্ট্যাটাস নিজে বদলানো যায় না
- `NODE_ENV=production` হলে ইন্টারনাল এরর মেসেজ বাইরে যায় না

## ড্যাশবোর্ডের ডেটা

`Admin Accounts` সংখ্যাটা আসল ডেটাবেস থেকে আসে। বাকি সংখ্যা (ইউজার,
ডিপোজিট, উইথড্র, অ্যাফিলিয়েট) আপাতত স্ট্যাটিক — সংশ্লিষ্ট কালেকশন তৈরি
হলে `routes/dashboardRoutes.js` এ শুধু কোয়েরিগুলো বসালেই হবে।
